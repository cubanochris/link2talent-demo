# Link2Talent AI Receptionist Demo

Live demo of our AI receptionist platform with chat and voice capabilities powered by Retell AI.

## Features

- 🎙️ **Voice Calls** - Real-time voice conversations with AI receptionist
- 💬 **Chat** - Text-based conversations
- 📅 **Appointment Booking** - Schedule appointments automatically
- 📊 **Lead Capture** - Collect customer information
- 24/7 **Availability** - Always on, always responsive

## How to Use

### Live Demo
Visit the live demo: [AI Receptionist Demo](./AI%20Receptionist%20Demo.html)

2. Click the chat bubble in the bottom right
3. Choose to **Chat** or **Call**
4. Start your conversation!
